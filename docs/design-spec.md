## 一、色彩：一套 oklch 令牌，hue 驱动全色板

全部颜色由 `hue`（0–360）+ 固定的 L/C 三元组算出（`OklchColor()`），
换主色时**只改 hue**，整套色板一起变。默认 `hue = 250`，取自壁纸时按
OKLCH 色度加权圆均值。

### 令牌表

| 令牌 | 浅色 L C | 深色 L C | 用在哪 |
| :--- | :--- | :--- | :--- |
| `primary` | `.70 .14` | `.75 .14` | 强调条、开关、滑杆填充、选中环、hue 滑钮 |
| `chipBg` | `.95 .025` | `.33 .035` | 图标 chip 底、侧栏选中底、开关关态、滑杆槽、关闭钮 hover |
| `chipFg` | `.55 .12` | `.75 .10` | chip 里的图标线条 |
| `title` | `.25 .020` | `.88 .010` | 标题、行名、按钮主文字 |
| `detail` | `.42 .020` | `.70 .015` | 明细、说明、值文本、窗口标题 |
| `card` | `1.0 0`（白） | `.23 .015` | 卡片底（带不透明度 alpha） |
| `page` | `.95 .010` | `.16 .014` | 设置窗口背景 |
| `divider` | `rgba(0,0,0,.086)` | `rgba(255,255,255,.14)` | 行分隔线 |
| `itemBg` | = `chipBg` | = `chipBg` | 侧栏选中底、hover 底 |
| `itemFg` | = `chipFg` | = `chipFg` | 侧栏选中文字/图标 |

（代码：`MakePalette(darkCard, cardAlpha)`，`hspec.cpp`）

### 三条硬约束

1. **界面层不写死色值。** 任何新控件先问「这颜色对应哪个令牌」，没有就先加令牌，
   不许在绘制代码里出现 `Color(255, a, b, c)` 之外的字面色。
2. **浅色 `detail` 不得亮过 L≈0.45。** 文本按「灰度抗锯齿 → 亮度反推 alpha」合成
   （`DrawTextGdiLine`），底色与文字色越接近反推误差越大。`.42 .02` 已在安全线内，
   再浅就会边缘发软。
3. **卡片不透明度不得低于 0.80。** 桌面图标在壁纸之上、面板之下，会从卡片里透出来。

## 二、字体：一面字重，无粗体

**只嵌 MiSans Medium（500）一面，全文 `FW_NORMAL`。** 层级只靠字号 + 颜色。
理由：GDI 合成加粗经 alpha 反推后边缘发灰（「发虚」），真 Bold 字面已被明确否决。
新增文本一律 `FW_NORMAL`（见 `tools/subset_font.py` docstring）。

### 设置窗口字阶（dp，乘 `SettingsScale()`）

| 字号 | 用途 | 例 |
| :--- | :--- | :--- |
| **24** | 页标题、关于页 hero | 「外观」「轻谱 Hydrogen Spec」 |
| **18** | 节标题 | 「主题」「主色」「面板」 |
| **16** | 功能行名（显示内容） | 「处理器」「主板与固件」 |
| **15** | 行名（滑杆）、侧栏项、按钮 | 「卡片不透明度」「外观」「GitHub 仓库」 |
| **14** | 页副标题、滑杆值、主题缩略图注、窗口标题、关于信息键 | 「关掉的项目不再出现在面板上」 |
| **13.5** | 说明、meta、hue 值、关于信息值、版本号 | 「从壁纸采样主色，换算成 oklch 的 hue」 |
| **12** | 页脚、版权 | 「HSpec 1.0」「© 2026 …」 |

### 桌面板字阶（dp，乘面板 DPI）

| 字号 | 用途 |
| :--- | :--- |
| **16** | 行标题（「主板: LNVNB161216」） |
| **14** | 明细行（「厂商: 联想」） |

行高：标题 24dp、明细 21dp、行距 9dp（`g_titleH/g_detailH/g_rowGap`）。

## 四、控件规格

**开关**：开 = `primary` 底 + 白圆钮靠右；关 = `chipBg` 底 + 白圆钮靠左。
无描边，无阴影。

**滑杆**：槽 = `chipBg` 4px 圆头线；已划过部分 = `primary`；滑钮 = 白色 13px 圆
+ 1px 半透明描边环（浅色 `rgba(0,0,0,.125)`，深色 `rgba(0,0,0,.157)`）。

**单选（主题三选一）**：缩略图 161×84 程序化绘制（`DrawThemeThumb`），
选中态 = 2px `primary` 外环 + 6px 内留白；下方 14dp 名称 + 圆形指示点。

**侧栏项**：选中 = `itemBg` 圆角 12 底 + `itemFg` 图标文字；未选 = `detail` 色，
无 hover 底（设置窗口只有点击，无 hover 高亮——保持现状）。

**强调条**：页标题左侧 4×24 圆角 2 的 `primary` 竖条。这是全 UI 唯一的
「装饰性」元素，别的地方不要再加。

**图标 chip**（面板卡片模式）：30×30 圆角 9 的 `chipBg` 方块，内置 24dp
线性图标（`chipFg` 描边）。图标是矢量绘制，不是字体图标。

## 五、三个渲染层（面板主题）

同一信息模型，三种渲染层。**不换布局只换画法**，文字列宽保持一致
（不因主题切换出现省略号）。

| 主题 | 画法 | 适用 |
| :--- | :--- | :--- |
| **纯文字** | 文字直贴壁纸，无底无边 | 极简桌面、PE，零存在感 |
| **轻卡片** | 白/深色实心卡片，图标 chip | 可读性优先，壁纸再乱也稳 |
| **Ethereal** | 半透明卡片 + 壁纸模糊底 + 主色图标 | 与壁纸融合但可读 |

明暗判定拆两层：`sheet = f(壁纸亮度)`（用浅卡还是深卡）、`text = f(sheet)`（文字色）。
**不能**用壁纸亮度直接决定文字色，否则浅壁纸上会出「白卡白字」。

## 六、交互（面板可点击 · 设计目标）

面板当前 `WS_EX_TRANSPARENT` 全穿透。可点击版按下述状态机设计：

| 状态 | 画法 |
| :--- | :--- |
| 默认 | 同现在 |
| hover 行 | 行区域圆角 8 的 `itemBg` 底（约 60% alpha），即时跟随 |
| 点击行 | 该行信息复制到剪贴板 + 行内闪现「已复制」提示（1s 淡出） |
| 点击空白 | 打开设置窗口 |
| 右键 | 托盘同款菜单（设置… / 刷新 / 退出） |

命中区表（rect + 动作）布局时重建，与设置窗口同一套机制（`HitAdd`）。
键盘不抢焦点（桌面浮层不进 Tab 序）。

## 七、程序化绘制约定

- **缩略图零图片资源**：`DrawThemeThumb(g, rect, hue)` 跟着 hue 自动变，
  不内嵌 PNG（改主色不用重出图，也不和真实渲染脱节）。
- 缩略图内**不画真字**，只画色块和条（小尺寸下中文 AA 糊成一团）。
- 新增界面文案要进 `tools/hardware_words.txt` 后重跑 `tools/subset_font.py`，
  否则子集外的字整行回退雅黑，字重字面都不一样。
